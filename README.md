# Estelle × La Vie

Landing de candidature d'Estelle Lavenac, designer graphique senior (print, web & motion), pour La Vie.

« Le combo parfait : du bacon végétal et Estelle. »

- Page autonome : `index.html` + dossier `assets/`, aucune dépendance à installer.
- Animations en CSS, et les yeux du cochon et d'Estelle suivent le curseur (JavaScript léger).
- Polices : Gunnar si installée, sinon Barlow Condensed / Barlow Semi Condensed (Google Fonts).

CV en ligne : https://estellelavenac.github.io/Estelle-Lavenac/
